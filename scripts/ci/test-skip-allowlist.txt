# The test job runs as the unprivileged `ci` user on Linux. A root-level test
# that reports Action=skip is *observed* by test-inventory.py, but skip is not
# execution evidence: a required gate that soft-skips still produced no
# assertion (issue #430). Any skip outside this list fails the inventory.
#

# condition for THIS job — e.g. requires root or live systemd, which the base
# image deliberately does not grant. Do not add entries for "tool missing" or
# "network unavailable" skips: CI provides node/caddy/network, so those tests
# must run (their absence is the false-green this file exists to catch).
#

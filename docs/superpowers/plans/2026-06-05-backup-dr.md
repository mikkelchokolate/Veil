# Backup And Disaster Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Turn the existing encrypted state archive into a verifiable,
scheduled, retained, cross-host disaster-recovery feature with bounded Panel
controls.

**Architecture:** Preserve encrypted archive versions 1 and 2 for restore
compatibility. Add a versioned manifest inside new archives with checksums,
creation metadata, Veil version, and Management schema version. Centralize
decrypt/inspect/verify before any restore writes. Scheduled jobs use a
root-owned passphrase file and shipped systemd oneshot/timer units; retention is
implemented in the CLI and shared with the Panel API.

**Tech Stack:** Go 1.25, AES-256-GCM, PBKDF2-SHA256, tar/gzip, Cobra, systemd,
existing Management state codec and Panel API.
